# claude

Repositório do curso de Claude: exercícios, anotações e projetos feitos durante o curso.

## Como usar

Clone o repositório:

```bash
git clone https://github.com/thiagotda/claude.git
cd claude
```

## Como contribuir

1. Crie uma branch a partir da `main`: `git switch -c minha-mudanca`
2. Faça suas alterações e commit.
3. Envie a branch e abra um Pull Request.
